# Chat-Socket.io
¡Bienvenido/a! Este proyecto es un Chat con la librería de JavaScript "Socket.io" que permite la comunicación bidireccional en tiempo real.

## CARACTERISTICAS

* Comunicación Bidireccional en Tiempo Real.
* Arquitectura Basada en Eventos (emit y on).
* Servidor de Node.js Dedicado.
* Cliente Web Ligero (HTML/CSS/JS).
  
## DESARROLLO EN

- Backend: JavaScript con Node.js.
- Frontend: HTML, CSS3.
- Librerias: Socket.io,Nodemon.
  
## INSTALAR APLICACION

Si deseas clonar este proyecto y ejecutarlo en tu computadora, sigue estos pasos:

1. **CLONAR REPOSITORIO**
    ```bash
        git clone https://github.com/mireyalopezdev/Chat-Socket.io.git
        cd Chat-Socket.io
     ```
    
2. **INSTALAR DEPENDENCIAS**
    ```bash
        npm install
     ```
    
3. **INICIAR EL SERVIDOR BACKEND**
    ```bash
        npm start
     ```
4. **INICIAR EL SERVIDOR CLIENTE**
    ```bash
        npm run client
     ```
5. **VER APLICACION**
   Visita **http://127.0.0.1:8080** o **http://localhost:8080** en tu navegador.
